# LCAI-0014A — Contenus pédagogiques non français

## Méthode

168 questions liées à une version Approved ont été inspectées en lecture seule.
La détection combine le code de langue et des marqueurs lexicaux simples. Aucun
contenu pédagogique n’a été modifié.

## Résultat

Quatre contenus en anglais ont été détectés. Ils appartiennent tous à la matière
Anglais : leur langue est donc pédagogiquement justifiée et ne nécessite pas de
traduction automatique.

contenu Approved dans une autre matière n’a été classé comme anglais par ce
contrôle.
