# LCAI-0011C — Audit pédagogique final après correction

Échantillon aléatoire : 35 chapitres, tous issus des 152 chapitres qui
utilisaient auparavant un profil générique. Les 14 overrides ne sont donc pas
utilisés pour améliorer artificiellement le résultat.

Légende :

- **D** : compétence disciplinaire de contenu ;
- **M** : compétence méthodologique complémentaire ;
- **Sous-compétences** : uniquement celles persistées comme telles ; `—`
  signifie que les compétences constituent déjà les unités diagnostiques.

## Conclusion de l'audit

- Chapitres audités : **35/35 non-overrides**.
- Chapitres permettant deux profils de maîtrise différents : **35/35**.
- Chapitres permettant une remédiation disciplinaire ciblée : **35/35**.
- Chapitres où une méthode générique remplace encore le contenu : **0/35**.
- Les compétences méthodologiques sont complémentaires et identifiées comme
  telles ; elles ne constituent plus la seule décomposition.

Réponses aux deux critères d'acceptation :

1. Deux élèves peuvent-ils maîtriser des parties différentes du même chapitre
   et recevoir des profils différents ? **Oui, dans 35/35 cas audités.**
2. Le futur Content Factory peut-il cibler une compétence disciplinaire
   précise ? **Oui, dans 35/35 cas audités.**
