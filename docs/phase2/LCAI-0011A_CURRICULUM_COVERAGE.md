# LCAI-0011A — Curriculum Coverage Matrix

## Status vocabulary

- **AVAILABLE**: grade-bound curriculum and Approved content exist.
- **PARTIAL**: some target curriculum exists, but subject or programme coverage
  is explicitly non-exhaustive.
- **NO APPROVED CONTENT**: curriculum exists but has no learner-eligible
  content.
- **MISSING**: no grade-bound curriculum structure exists.
- **NOT MODELLED**: the target relationship itself is absent.

Reference-level subjects and domains are not counted as grade curriculum unless
they are connected through a programme/chapter/skill placement.

## Coverage interpretation

- No existing node is classified **AVAILABLE** as a complete official
  programme. The source catalog explicitly describes itself as targeted and
  non-exhaustive.
- There are currently no examples of a grade-bound chapter with zero Approved
  content. The schema permits that state, but the bundled import couples the
  two datasets.
- The 68 Approved rows represent 34 normalized pedagogical questions.
- Curriculum expansion must precede content expansion; zero-content nodes must
  remain visible only in curriculum-oriented APIs and honest empty states.
