# Guide de rédaction pédagogique

Chaque contenu doit être original ou disposer d’une origine et d’une licence explicites. Le lot LCAI-0009 est déclaré « Contenu original interne — licence projet ».

Un contenu publiable comporte :

- un code stable, une version, un titre et un résumé ;
- un niveau, programme, matière, domaine, chapitre, compétence, sous-compétence et objectif ;
- une difficulté 1 à 5 accompagnée d’une justification ;
- une durée minimale, estimée et maximale ;
- un énoncé précis et un type de réponse stable ;
- une réponse attendue et un corrigé structuré s’il est évaluatif ;
- des indices ordonnés et pénalisés ;
- des erreurs fréquentes décrites sans détection automatique fragile ;
- des tags issus du référentiel ;
- auteur/source, licence, dates, reviewer et approver.

Éviter les compétences non observables, les questions ambiguës, les variantes artificielles d’un même exercice et toute affirmation de couverture exhaustive. Aucun LLM ni correcteur libre n’intervient dans le pipeline.
