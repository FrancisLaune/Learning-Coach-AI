# LCAI-0018B6 — Pack Cursor

Ce pack impose la généralisation de la génération IA des exercices lorsque le
catalogue est insuffisant.

Cas prioritaire à auditer : **Espagnol 4e — seulement 2 rubriques visibles**.

Le moteur doit générer le déficit, valider les exercices, les persister et les
rendre immédiatement jouables.
