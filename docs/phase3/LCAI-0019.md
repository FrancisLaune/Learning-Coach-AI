# LCAI-0019 — Plateforme d'intelligence pédagogique V1

**Statut :** En cours  
**Date :** 2026-07-30  
**Prérequis :** LCAI-0018 (catalogue), LCAI-0010 (moteurs learning/decision/intelligence)

## Objectif

Construire la couche d'intelligence pédagogique en **réutilisant** le catalogue et les moteurs V2 existants, sans IA générative.

## Périmètre V1

| Bloc | Contenu |
|------|---------|
| Parcours cibles | **CM1 → CM2**, **4e → 3e** |
| Capacités | Diagnostic adaptatif, profil, maîtrise, lacunes, planner, readiness, recommandations, dashboards |
| Exposition | Streamlit + controllers (pas de REST V1) |
| Schéma | Extension V2 (migration 022), pas de tables parallèles |

## Décisions d'architecture

1. **Pas de REST API** — controllers application existants
2. **Facade `PedagogicalIntelligenceService`** — branche learning engine, decision, intelligence
3. **Formules maîtrise/readiness** — autorité `domain.learning` (pas de second moteur)
4. **CM2 multi-matières** — prérequis contenu satisfait (LCAI-0018D, 24/24 chapitres)

## Definition of Done V1

- [ ] Diagnostiquer un élève sur parcours CM1→CM2 ou 4e→3e
- [ ] Afficher readiness (READY / ALMOST_READY / NOT_READY)
- [ ] Alimenter dashboards parent/élève (progression, lacunes, planning)
- [ ] Tests unitaires + audit phase0 verts
- [ ] Aucune rupture API Streamlit existante

## Hors scope V1

REST/OpenAPI, profil cognitif complet, IA générative, prédiction de notes, comparaison entre élèves.
